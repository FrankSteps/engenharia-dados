# RELATÓRIO DE DESENVOLVIMENTO DA PRIMEIRA ATIVIDADE PARA A PRIMEIRA UNIDADE

## Árvore de diretórios

```bash
atividade-um
├── builds      # executável
├── docs        # orientações em PDF do professor
│   └── Engenharia_de_Dados__-_Atividade_1-1.pdf
├── input       # arquivo que será passado como parâmetro de entrada
│   └── dis-csv-discentes-de-graduacao-de-2026.csv
├── output      # arquivo gerado pelo programa
├── src         # programa
│   └── atividade-um.c
├── makefile # arquivo responsável pela execução automatizada do programa
└── README.md
```

> 2° Nota: Atualize este README sempre que possível

# DETALHES DE UTILIZAÇÃO

```bash
Objetivo do programa: Salvar todos os dados dentro de um arquivo.csv em um arquivo.txt. Além disso é possível fazer a consulta de um discente
através de sua matricula pelo terminal.

Como usar: Acesse o diretório "/atividade-um" e abrir o terminal no mesmo. Para executar o programa é só rodar o comando "make run",
para ajuda sobre a execução é só rodar no mesmo terminal o comando "make help".

Como encerrar o programa: Digite ".." no campo onde é solicitado a matricula.
```
